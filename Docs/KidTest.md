# 子どもテストの記録

担当：D（D_ui.md Step 12・16・18）。
テストのたびに、下の「1回目」と同じ形で記録を足す。Claude Code は記録をもとに「直すことの一覧」を作る。

## テストのやり方（毎回同じ）

1. チーム外の人（できれば子ども、いなければ子ども役）に、iPhone、検証用の物のセット、たかさものさしを渡す
2. 言うことは、これだけ：「つくえに ものを ならべて、ステージを つくって あそんでね」
3. あとは横で見て、聞かれても答えない（どうしても止まったら、何に困ったかを聞いてから助ける。助けた時刻と内容を書く）
4. ストップウォッチで2つの時間を計る
   - 並べる時間：物を並べ始めてから「スキャンする」を押すまで
   - 遊べるまでの時間：「スキャンする」を押してから「あそぶ」を押すまで（品質目標は、並べ終わってから3分以内）
5. 並べ終えた物と、できたステージ（たしかめ画面）の写真を撮る

## 準備するもの

- [ ] iPhone（A が作った、合流した版のアプリ。充電しておく）
- [ ] 検証用の物のセット（段ボール箱、積み木、本など。B の Docs/SampleLayout.md の物）
- [ ] たかさものさし（Docs/HeightGauge.pdf を実物大で印刷し、厚紙に貼る）
- [ ] ストップウォッチ（スマホの別の端末でよい）
- [ ] この記録（印刷するか、ノートPCで開く）
- [ ] 写真を撮る端末
