# D：UI・見た目 Claude Code 作業手順

先に Docs/ClaudeCode/00_overview.md を読んでください。このファイルの名前（クラス、イベント、依頼）は、すべて 00_overview.md の4章の共通コードに合わせています。

## Dの仕事

子どもが触るすべての画面と、ステージやキャラの見た目を作ります。とくに大事なのは、子どもが「机に物を並べる → スマホで映す → 遊ぶ」を説明なしで進められる画面と、並べるときの手助けです。他の3人の状態や出来事を、子どもに分かる形で伝える役でもあります。子どもテストの実施も D が担当します。

完成の姿：子どもが机に物を並べ、説明なしでスキャンし、本物の物の上にスタートとゴールを置いて、並べ終わってから3分以内に遊び始められる。物の上面が見つかるたびに箱が生える楽しい反応がある。遊んだあと、物を並べ直して何度でも作り変えたくなる。

## 子どもが使う画面の決まり（すべての Step で守る）

- 文字は少なく、短く、ひらがな中心（【未決】対象の年齢。決まるまでは小学校低学年として作る）
- 操作はタップ、1本指でなぞる、2本指でつまむ・ひねる、だけ。長押しやダブルタップは使わない（デバッグ表示の切り替えだけは例外）
- ボタンと取っ手は大きく（基準の解像度で直径160以上）
- 何かしたら、必ず目と耳に分かる反応を返す（箱がぽんと出る、色が変わる、短い音）
- 画面の上で直すより、現実の物を並べ直すことをすすめる
- 画面は横向き固定。部品はすべて安全な範囲（SafeArea）の内側。日本語フォントを使う
- 色だけで意味を伝えない（緑・赤の印には、絵や文字も付ける）
- 画面の文はすべて1つの表（Docs/Wording.md）にまとめ、そこから読む（あとで年齢に合わせて直しやすくする）

## 7つの画面

| 画面 | 表示するとき | 主な部品 |
| --- | --- | --- |
| タイトル | 起動直後 | はじめる |
| ステージ一覧 | はじめる、クリアや一時停止から戻ったとき | ステージの名前、最速記録、あそぶ、けす、あたらしくつくる |
| ならべかたのコツ | あたらしくつくる | 並べ方の絵、たかさものさしの絵、スキャンする |
| スキャン | スキャンする | カメラ映像、案内、見つけた箱の数、箱が生える演出、できた |
| たしかめ | できた | カメラ映像の上の箱、段の印、なおす（補助）、スタート・ゴール・チェックポイント、もういちどスキャン、ほぞん、あそぶ |
| プレイ | あそぶ | 3D画面、スティック、ジャンプ、経過時間、一時停止 |
| クリア | Goal の知らせ | タイム、新記録の印、もういちど、ならべなおす、ステージ一覧へ |

## M1

### Step 4：視点の操作（ViewGesture）【CC＋人】

- やること
  1. プレイ画面で、スティックとボタン以外の場所をなぞったら、横と縦の量を OrbitView で出す
  2. 2本指でつまんだ・広げたら、ZoomView で出す
  3. スティックを操作している指は、視点に使わない
- 確認：【人】実機で、スティックで走りながら右手で視点を回せる

### Step 5：案内の表示（GuidanceView）【CC＋人】

- やること：ScanStatusChanged に合わせて、画面の上の中央に1行の案内を出す。状態が戻ったら1秒後に消す

| 状態 | 理由 | 案内 |
| --- | --- | --- |
| Starting | ― | じゅんび しているよ |
| FindingDesk | ― | つくえを うつしてね |
| FindingDesk（10秒たった） | ― | つくえの うえを ゆっくり うつしてね |
| FindingDesk（机の面が見つかった） | ― | つくえを タップしてね |
| Scanning | ― | つくえの まわりを ゆっくり あるいてね |
| Limited | Dark | へやを あかるく してね |
| Limited | FastMotion | もっと ゆっくり うごかしてね |
| Limited | FewFeatures | つくえの ほうに むけてね |
| Lost | ― | もういちど つくえを うつしてね |

- 確認：【人】実機で、手で覆う・速く振る・白い壁を映す、で正しい案内が出る

### Step 6：デバッグ表示（DebugOverlay）【CC＋人】

- やること
  1. 画面の左上に小さく重ね、3本指のダブルタップで表示・非表示を切り替える。Development Build でないビルドでは出さない
  2. 各担当が「名前と値」を登録すると一覧に出る仕組みにする
  3. 最初から出すもの：フレームレート、スキャン状態と理由、スキャン開始からの秒数、上面の数と箱の数（auto・manual）、ゲームの状態
  4. 箱をタップすると、その箱の id、大きさ、高さ（cm）を出す（B の読み取りの測定と、C の報告に使う）
  5. 切り替え：A の PlaneProbe、当たり判定の枠の表示
  6. スライダー：歩く速さ、重力、ジャンプの高さ（C の CharacterSettings を変える）
- 確認：【人】実機で箱をタップすると id と高さが出る

### Step 7：見た目の素材と光源【CC＋人】

- やること
  1. 【CC】Rendering/ に素材を作るエディタ用スクリプト

| 素材 | 使う物 | 見た目 |
| --- | --- | --- |
| ScanSurface | A の上面の表示 | 明るい水色、半透明（不透明度 0.35）、ScanView レイヤー |
| DeskOutline | スキャン中の机の板 | 枠の線だけ（カメラ映像の机が見えるように） |
| BoxScan | スキャン中・たしかめ画面の箱 | 半透明（不透明度 0.6）、本物と見比べられる |
| BoxPlay | 遊ぶ画面の箱 | 明るい色。箱ごとに数色から順に、隣どうしが同じ色にならないように |
| DeskPlay | 遊ぶ画面の机の板 | 木目のような落ち着いた色、縁を少し濃く |
| BoxSelected | 補助で選んだ箱 | ふちを太い黄色の線で光らせる |

  2. 【CC】B の StageBuilder が場面（Scan、Check、Play）に合わせて素材を選べるよう、素材の組を設定アセットにまとめて渡す
  3. 【CC】遊ぶ画面の光源（Directional Light、斜め上から、Soft Shadows）と、影の設定（影の距離は机の大きさに合わせて 1〜2m、Bias は小さめ）。背景は明るい単色（【未決】カメラ映像にすると決まったら変える）
- 確認：【人】遊ぶ画面で、キャラと箱の影が机の板に落ち、キャラの影が足元から離れない

### Step 8：スキャン画面（ScanScreen）【CC＋人】

- やること
  1. 机の面が見つかったら薄く光らせ、「つくえを タップしてね」を出す。タップで SetDesk を出す
  2. DeskDecided を受けたら、机の長方形の枠をなぞるように光らせ（1秒）、短い音を鳴らす
  3. 画面の上に「みつけた はこ：3」と箱の数を大きく出す
  4. SurfacesChanged で上面を ScanSurface の素材で光らせる
  5. BoxesChanged で箱が足されたら、本物の物の上で箱が机から「ぽん」と伸びて生える演出（0.3秒）と短い音
  6. 机の長方形のうち、面が見つかっていない側があれば、その方向を指す小さな矢印を出す（出し方は子どもテストで決める）
  7. 右下に大きな「できた」。押したら FinishScan を出し、たしかめ画面へ
- 確認：【人】お手本の並べ方をスキャンすると、上面が光り、箱が生え、数が増える

### Step 10：たしかめ画面：箱と段の印、もういちどスキャン（CheckScreen）【CC＋人】

- やること
  1. B の箱を BoxScan の素材で本物の物に重ねて見せる
  2. 各箱の上面に、隣の面との高さの差を C の StepRules で判定した印を出す（Jump は緑と「とぶ」の絵、Wall は赤と「ばつ」の絵）
  3. Wall の箱のそばに「とどかないよ。ひくい ものを となりに おいて、もういちど スキャンしてね」を小さく出す
  4. 上の中央に「ほんものと おなじかな？」
  5. 左上に「もういちどスキャン」。押したら「はこを ぜんぶ つくりなおすよ。いい？」と確かめ、Rescan を出してスキャン画面へ
- 確認：【人】8cm の箱の横に何もないと赤の印が出る。本物の積み木を横に置いてもういちどスキャンすると緑になる

### Step 11：たしかめ画面：読み取りの補助【CC＋人】

- 目的：見つからなかった物や違う箱を、子どもが画面で直せるようにする（補助だけ）
- やること：左下の「なおす」を押したときだけ、下の操作を出す。もう一度押すと閉じる

| したいこと | 子どもの操作 | 出す依頼 |
| --- | --- | --- |
| 見つからなかった物に箱を足す | 「＋はこ」を押してから、本物の物の上をタップ | AddBox |
| 箱を選ぶ | 箱をタップ | SelectBox |
| 本物に合わせて動かす | 選んだ箱を1本指でなぞる | MoveBox |
| 高さを合わせる | 選んだ箱の上の「上下の取っ手」をなぞる | ResizeBox（高さ） |
| 幅・奥行きを合わせる | 2本指でつまむ・広げる | ResizeBox（幅・奥行き） |
| 向きを合わせる | 2本指でひねる | RotateBox |
| 本物にない箱を消す | 選んだ箱の横の「けす」 | DeleteBox |
| 元に戻す | 「もどす」 | UndoBox |

- 決まり：指で動かしている間は、箱が指にぴったりついてくるように見せ、離したら B のそろえた位置へなめらかに寄せる。2本指は、最初に大きく変わった方（距離か角度か）だけを使う。選んだ箱は BoxSelected で光らせる。「＋はこ」を押した後は、ボタンの色を変えて「おきたい ところを タップしてね」を出す
- 確認：【人】見つからなかった積み木の場所に箱を足し、高さを本物に合わせられる。すべて「もどす」で戻る

## M3

### Step 13：たしかめ画面：スタートとゴール、保存【CC＋人】

- やること
  1. 下の中央に「スタート」「ゴール」「チェックポイント」の切り替えボタンを絵と一緒に置く
  2. 本物の物（箱）の上をタップしたら、PlaceCourseItem を出す
  3. CoursePlaced の結果で：置けたら目印を出す。置けないなら理由の文を1秒出す。「とどかないかも」なら、ゴールのそばに「？」の印と Step 10 の3の案内
  4. 右下の「ほぞん」は、スタートとゴールの両方が置かれるまで押せない。押したら名前を決める小さな画面（初期値「つくえ 1」、そのまま OK でもよい）を出し、SaveStage を出す
  5. SaveCompleted で「ほぞん したよ」か「ほぞん できなかったよ」を出す。保存できたら大きな「あそぶ」を出し、押したら Play を出してプレイ画面へ
  6. 保存せずに戻ろうとしたら「ほぞん していないよ。もどる？」と確かめる
- 確認：【人】子どもが説明なしで、本物の物の上にスタートとゴールを置いて保存し、遊べる

### Step 14：ステージ一覧、プレイ画面、クリア画面【CC＋人】

- やること
  1. ステージ一覧：B の一覧を新しい順に出す。「読み込めません」のステージは灰色にして選べないようにする。「あそぶ」で SelectStage → StageBuilt を待って Play。「けす」は確かめてから消す（消す依頼は B と決め、共通コードに足すなら 2.2 のとおり）。「あたらしくつくる」でならべかたのコツへ
  2. プレイ画面：左下スティック、右下ジャンプ、上の中央に経過時間（ElapsedTime、「0:12.34」の形）、右上に一時停止（メニュー：つづける、もういちど、ステージ一覧へ。SetPaused、Retry、BackToList を出す）、中央に出来事の短い表示（「チェックポイント！」「おちちゃった」を1秒）
  3. クリア画面：Goal でタイムを大きく出し、最速記録なら「しんきろく！」。「もういちど」で Retry、「ならべなおす」でならべかたのコツへ、「ステージ一覧へ」で BackToList
  4. 端末の温度：ThermalStateChanged で「高い」なら影を切る。「危険」なら「スマホが あつく なったよ。すこし やすもう」を出して一時停止する
- 確認：【人】一時停止メニューの3つが動く。クリアから「ならべなおす」で作り直しに進める

## 困ったとき

| 起きていること | よくある原因 | 直し方 |
| --- | --- | --- |
| 日本語が四角に化ける | フォントに日本語がない | 日本語フォントのアセットを使う |
| ボタンが角や切り欠きに隠れる | 安全な範囲の外 | すべて SafeArea の中に入れる |
| スティックとジャンプが同時に押せない | 複数の指の操作が切られている | 実機で確かめる（PC のマウスでは確かめられない） |
| 物を並べずにスキャンを始める | コツが伝わっていない | 絵を大きくし、「ものを ならべたら おしてね」をボタンの上に出す |
| 「なおす」ばかり使う | 読み取りの失敗が多い | 子どもテストで物の種類を記録し、A・B に伝える。コツを直す |
| 箱を動かそうとすると別の箱が選ばれる | 手前の箱に光線が当たる | 「まわりこんで えらんでね」を出す |
| つまむとひねるが混ざる | 両方を同時に送っている | 最初に大きく変わった方だけを使う |
| 影が出ない、足元から離れる | 光源の影がオフ、Bias が大きい | Step 7 の3 を確かめる |
| 影がしま模様になる | Bias が小さすぎる | 少しずつ大きくする |
