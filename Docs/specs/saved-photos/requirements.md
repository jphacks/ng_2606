# saved-photos

> 2026-11-07 のユーザーの指示「もう一度遊ぶを押すとプレイヤーが出てこない問題と、保存されたステージの写真が消えてしまう問題を解決しなさい」で直す。
> 写真を保存に残すやり方は、2026-11-03 に私が提案した案（箱ごとの上面の写真を保存して、読み込むときに貼る）。

## 何を直すか

1. 遊んだあと「コースを なおす」などでたしかめの画面に戻り、もう一度「あそぶ」を押すと、キャラが出てこない
2. 保存したステージを開くと、箱の上の写真が無い（保存に写真を入れていなかった）

## なぜ起きるか

1. 遊ぶ画面を出ると、ゲーム側が「ステージを片付けた」扱いにする（GameFlowState.BackToList で StageReady を消す）。たしかめの画面にはステージが残っているのに、もう一度遊ぶとき「ステージの準備ができた」知らせが来ないので、キャラを出さない
2. 箱の写真は、撮った 1 枚目からその場で切り出して貼るだけで、保存していなかった

## 完成の条件

- [ ] REQ-1: たしかめの画面から、何度「あそぶ」を押しても、キャラが出て遊べる
- [ ] REQ-2: 保存するとき、箱ごとに上面の写真を切り出して、ステージのフォルダに保存する（`face-<箱の id>.jpg`、長い辺 256 画素）。BoxData.texture に、そのファイルの名前を入れる
- [ ] REQ-3: 保存したステージを開くと、保存した写真を、箱の上に貼る（横は、写真の平均の色を暗くした色）
- [ ] REQ-4: 写真は、この iPhone の中だけ（外へは送らない）
- [ ] REQ-5: ファイルの名前は決まった形だけ読み、ステージのフォルダの外を読まない。写真が無い・読めないときは、写真なしで遊べる

## やらないこと

- 前に保存したステージ（写真を保存していなかった物）に、写真を戻すこと
- 坂以外の箱の側面に、写真を貼ること
