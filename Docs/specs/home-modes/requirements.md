# home-modes

> **2026-11-07：「みんなの ステージ」（REQ-9〜13 と、REQ-1 の 3 つ目のモード）は、ユーザーの指示で消した。** モードは「ステージを つくる」「おだいで つくる」の 2 つ。投稿のサーバーの口（/stages）とテストも消した。

## 何を作るか

最初の画面で、遊び方（モード）を 3 つから選べるようにする（ユーザーの依頼：2026-11-06）。

1. **ステージを つくる**：いまの流れ（撮影 → たしかめ → コースとしばり → あそぶ・ほぞん）
2. **おだいで つくる**：お題（条件）が決まっていて、それを満たすステージを、遊ぶ人が撮って作り、遊ぶ。
   例：「はこを 5こ いじょう つかおう」「みずを いれよう」。お題を満たすまで遊べない。クリアするとスタンプがもらえる
   （2026-11-06 に依頼を言い直してもらった。最初は「製作者が作ったステージを遊ぶ」と受け取っていたが、ちがった）
3. **みんなの ステージ**：遊ぶ人が作って投稿したステージを、選んで遊ぶ

## なぜ必要か

いまは、自由にステージを作るだけで、作るときの目標が無い。お題に合わせて並べ方を工夫する楽しみ（おだい）と、
ほかの人が作ったステージを遊ぶ楽しみ（投稿）を足して、繰り返し遊べるようにしたい。

## 完成の条件

**モードを選ぶ**
- [ ] REQ-1: タイトルの次に、モードを選ぶ画面が出る。「ステージを つくる」「おだいで つくる」「みんなの ステージ」の 3 つ
- [ ] REQ-2: 「ステージを つくる」は、いまのホーム（自分のステージの一覧と、撮影）につながる。中身の流れは変えない

**おだいで つくる**
- [ ] REQ-3: 「おだいで つくる」を押すと、お題の一覧が出る。最初は 8 つ。達成したお題には、スタンプ（「できた！」）が付く
- [ ] REQ-4: お題は、次の条件を 1〜2 個組み合わせた物。条件は、撮ってできたステージ（たしかめの画面の箱と、置いたスタート・ゴール）から決まる
  - 箱の数：N こ いじょう ／ N こ まで（少なく作る）
  - しかけを入れる：水・炎・回復のどれか（どれも、をふくむ）
  - 坂を入れる
  - 高さ：N cm いじょうの箱がある ／ ゴールが N cm いじょうの高さ
  - 階段：高さのちがう箱が N 段 いじょう（2 cm いじょうずつ違う）
  - 距離：スタートとゴールが N cm いじょう離れている
- [ ] REQ-5: お題を選ぶと、いつもの撮影の流れ（撮り方の説明 → 撮影 → つくっている → たしかめ）に進む。撮影とたしかめの画面に、いまのお題が出る
- [ ] REQ-6: たしかめの画面に、お題の条件ごとに「できた」「まだ」が出る。箱を直す・スタートやゴールを置く・撮り直すと、すぐ変わる
- [ ] REQ-7: お題を全部満たすまで、「あそぶ」を押せない（押すと、まだの条件を伝える）。満たしたら遊べる
- [ ] REQ-8: お題を満たしたステージでクリアすると、そのお題にスタンプが付く（この iPhone の中に残す）。クリアの画面に「おだい たっせい！」が出る。タイムは競わない

**みんなの ステージ（投稿）**
- [ ] REQ-9: 自分の保存したステージを、「とうこう する」で投稿できる（ホームの自分のステージから）。投稿するのは、箱の形と位置・スタート・ゴール・チェックポイント・しばりと、ステージの名前だけ。写真（一覧の絵、箱の写真）は送らない
- [ ] REQ-10: 「みんなの ステージ」で、投稿されたステージの一覧（新しい順）が出る。選ぶと、読み込んで遊べる。記録は、この iPhone の中のベストタイム
- [ ] REQ-11: 投稿の置き場所は、この Mac のサーバー（いまの読み取りサーバーに口を足す）。同じ Wi-Fi・テザリングの中の人どうしで共有する。サーバーにつながらないときは、理由を出す
- [ ] REQ-12: サーバーは、投稿を確かめてから保存する：合言葉、大きさの上限、形の確認（数値の範囲、箱の数の上限）、件数の上限。保存の名前はサーバーが決め、送られた名前をファイルの名前に使わない。写真は受け取らない
- [ ] REQ-13: みんなの ステージの一覧の絵は、写真の代わりに、箱の形から描いた図（上から見た四角）を出す

**共通**
- [ ] REQ-14: みんなのステージを遊んでいるときは、「コースを なおす」「ほぞん」は出さない（自分のステージではないため）
- [ ] REQ-15: 決まり（お題の判定、スタンプ、投稿の形の確認、サーバーの確認）は、EditMode テストとサーバーのテストで確かめる
- [ ] REQ-16: どの画面からも、1 つ前の画面に戻れる（「もどる」か、それに当たるボタン）。遊ぶ画面は、まちがって押さないよう「いちじていし」→「やめる」の 2 段（2026-11-06 の依頼）

## やらないこと

- インターネット上のサーバー、みんなでのランキング（記録は、この iPhone の中だけ）
- 製作者が作ったステージを遊ぶモード（最初に作った公式ステージ 5 つは、依頼と違ったので消す）
- お題を、遊ぶ人が作ること（お題は、アプリに入れた 8 つだけ）
- 「しばりでクリア」のお題（今回は、作るときの条件だけ）
- 投稿の削除・通報・名前（作者名）。不適切な投稿は、この Mac のサーバーの保存場所から、人が消す
- 投稿したステージの、箱の写真の再現（写真は送らないので、箱は色で塗る）

## 未決の判断

なし（2026-11-06 にユーザーが決めた）
- 2 つ目のモードは「お題に沿って、遊ぶ人がステージを作って遊ぶ」（言い直し）
- お題の条件：箱の数・しかけ・坂・高さ（ユーザーが選んだ）。階段・距離・少なく作る は、「他に案も出して」に応えた私の案
- お題を満たすまで遊べない
- 達成はスタンプだけ（タイムは競わない）
- 最初に作った公式ステージは消す
- 記録は、この iPhone の中だけ。投稿の置き場所は、この Mac のサーバー。投稿の中身は、形・コース・しばりだけ（写真は送らない）
