# home-modes の設計

## 画面の流れ

```
タイトル → モードを選ぶ（新規 ModeScreen）
             ├ ステージを つくる → いまのホーム（HomeScreen）→ 撮影 …（変えない）
             ├ おだいで つくる → お題の一覧（新規 MissionScreen）→ 撮影 → たしかめ（お題の判定）→ あそぶ → スタンプ
             └ みんなの ステージ → みんなの一覧（新規 CommunityScreen）→ あそぶ → …
```

- AppScreenId に Mode・Mission・Community を足す（Official は消す）。タイトルの「はじめる」は Mode へ
- 遊ぶ・クリア・ゲームオーバーの画面は共通。みんなのときは「コースを なおす」「ほぞん」を出さない（AppFlow に、いま遊んでいるステージの出どころ Source を持たせる：Own / Mission / Community）
- クリア・ゲームオーバーの「いちらんへ」は、出どころの一覧へ戻る

## おだい（お題）

- お題は、コードの中の一覧（App/MissionCatalog.cs）。8 つ。それぞれ id・名前・条件（1〜2 個）
  1. はこ いっぱい：箱を 5 こ いじょう
  2. みずの みち：水を入れる
  3. あつい と ほっと：炎と回復の両方を入れる
  4. さかみち：坂を入れる
  5. たかい ところ：ゴールが 20 cm いじょう
  6. かいだん：高さのちがう段が 3 段 いじょう
  7. とおくの ゴール：スタートとゴールが 40 cm いじょう
  8. すくなく つくる：箱は 3 こ まで ＋ ゴールが 10 cm いじょう
- 判定（Gameplay か App の、画面に触れない計算：MissionRules）：StageData（箱・スタート・ゴール）から、条件ごとに「できた」「まだ」を返す。EditMode でテストする
- スタンプ：PlayerPrefs に、お題の id ごとに達成を残す（MissionStamps）
- 流れ：お題の一覧（MissionScreen）→ 選ぶと、AppFlow にいまのお題を持たせて、撮影の流れへ（StartNewStage と同じ）。撮影とたしかめの画面の上に、お題の名前を出す。たしかめの画面には、条件ごとの「できた／まだ」の列を出し、全部できるまで「あそぶ」を止める。クリアしたとき、お題を満たしていればスタンプを付け、クリアの画面に「おだい たっせい！」を出す。いちらんへは、お題の一覧へ戻る
- 公式ステージ（OfficialScreen、OfficialCatalog、StreamingAssets/Stages/official、そのテスト）は消す

## みんなの ステージ（この Mac のサーバー）

サーバー（Server/app.py）に口を 3 つ足す。どれも合言葉（X-App-Token）が要る。

- `POST /stages`：投稿。JSON（StageData から写真の項目を除いた物）を受け取り、確かめて保存する
  - 大きさの上限 200KB、箱の数の上限 100、数値は有限で範囲内、名前は 30 文字まで（制御文字を除く）
  - 保存先は `Server/shared_stages/<サーバーが決めた id>.json`。件数の上限（500）を超えたら断る
  - `texture`（写真のファイル名）は空にして保存する
- `GET /stages`：一覧（id・名前・投稿日時・箱の数・しばりの有無。新しい順、最大 100 件）
- `GET /stages/{id}`：1 件。id は英数字とハイフンだけ（パスに使わない形を、決まりで確かめる）
- `shared_stages/` は Git に入れない
- サーバーのテスト（標準の unittest。Server/test_stages.py）：合言葉・大きさ・形の確認・id の確かめ・件数の上限

アプリ：

- 送る・受け取る部品（StageShareClient、AR の ScanClient と同じ作法：接続先は ServerConfig、合言葉、http は LAN だけ）
- ホームの自分のステージの選んだ物に「とうこう する」ボタン。送る前に確認を出す
- CommunityScreen：一覧を読み、カード（名前・形の図・しばり・自分のベストタイム）を並べる。選ぶと 1 件を読み、StageLoaded と同じ道で組み立てて遊ぶ

## 形の図（写真の代わり）

- StageMiniMap（UI の部品）：箱の上から見た四角を、高さで色を変えて描く。しかけの箱は、しかけの色（青・赤・緑）。みんなの一覧のカードで使う

## 記録

- お題：達成のスタンプだけ（MissionStamps）。タイムは、自分のステージと同じく、ステージの id ごと
- みんな：ステージの id ごと
