# 箱のしかけ（折り紙の色）

2026-10-25 追加（西垣さんの指示）。箱の上面に折り紙を貼ると、色によって、遊ぶときのしかけが変わる。

## 決まり

| 折り紙 | しかけ | 遊ぶとき |
| --- | --- | --- |
| 青 | 水（`water`） | 箱の上で、箱ごとに決まった向き（前後左右の 1 つ）へ、少し流される（0.05 m/秒。歩く速さの 3 分の 1）。向きは矢印で見える |
| 赤 | 炎（`fire`） | 乗るとハートが 1 つ減る。減ったあとの 1.5 秒は、続けて減らない |
| 緑 | 回復（`heal`） | 乗っている間、1 秒ごとにハートが 1 つ回復する（最大 3） |
| 黄 | ジャンプ台（`jumppad`） | 乗ると自動で、ふつうのジャンプの 2 倍の高さ（約 24cm）まで跳ね上がる。跳ねたあとの 0.3 秒は続けて跳ねない |
| 紫 | 敵（`enemy`） | 7 秒ごとに、箱の上から敵が 1 体出る（机の上に同時に最大 5 体）。敵は出るたびに、キャラを追いかけるか、ランダムに歩き回るかを、くじ（半分ずつ）で決める。歩く速さはキャラの半分。段差は 0.9cm までしか登らず、下へは降りられ、机の外には出ない。当たるとハートが 1 つ減る（炎と同じく、減ったあとの 1.5 秒は続けて減らない）。もういちど・ステージ一覧へで全部消える |
| ピンク | ワープ（`warp`） | 踏むと、机の上か箱の上の、どこかランダムな所へ飛ぶ（机から落ちる所には飛ばない。キャラが入れない所も選ばない）。飛んだあとの 3 秒は、続けてワープしない |

- **一面その色のときだけ**。上面の写真（ふちを除いた内側）の 85% 以上が、同じ色のとき。少し入っているだけでは、しかけにならない（`GimmickDetector`）
- ハートは 3 つ。0 になると、ゲームオーバーの画面（もういちど／いちらんへ／コースをなおす）
- 落ちたときは、ハートは減らない（スタートへ戻るだけ）
- 色は、色相・彩度・明るさで見分ける。段ボール（茶色）、オレンジ、白、黒、灰色は、どれにもならない
- 色の範囲（2026-11-06 に黄・紫・ピンクを足した。新しい 3 色は実機でまだ測っていない）

| 色 | 色相（度） | 彩度 | 明るさ |
| --- | --- | --- | --- |
| 青 | 200〜250（前は 265 まで。紫と分けるため狭めた。実機の青は 213〜215） | 0.40 以上 | |
| 紫 | 250〜300 | 0.25 以上 | |
| 緑 | 75〜200 | 0.35 以上 | |
| 黄 | 40〜72 | 0.50 以上 | 0.45 以上 |
| ピンク | 300〜335、または赤の色相（335〜360・0〜14）で淡い色 | 赤の色相なら 0.18〜0.47 | 赤の色相なら 0.60 以上 |
| 赤 | 335〜360・0〜14 | 0.47 以上（前は 0.40。ピンクと分けるため上げた。実機の赤は 0.53 から） | 0.30 以上 |

## 共通データの変更（Shared）

`BoxData` に `gimmick`（`""`、`"water"`、`"fire"`、`"heal"`）を足した。古い保存データには無いので、読むと空（しかけ無し）になる。
保存（`StageSavePrep`）と、読み取りの補助（`BoxAssistCore.Copy`）で、この値を引き継ぐ。

## どこで何をしているか

- 色の判定：`Merge/GimmickDetector.cs`（計算だけ。テストあり）
- 撮ったときに判定して `BoxData.gimmick` に入れる：`Merge/StagePhotoTexturer.cs`
- 見た目と効き目：`App/GimmickSystem.cs`（板、炎、＋、流される、ハート、ジャンプ台、敵、ワープ）。ジャンプ台は C の `CharacterMotor.Launch`、ワープは `CharacterMotor.Teleport` を使う。C のゲームの中身は変えず、キャラの位置を読み、CharacterController に流される分だけを足す
- ハートの計算：`App/PlayerHealth.cs`、乗っている判定・水の向き：`App/GimmickRules.cs`
- 画面：プレイ画面の右上にハート、`App/GameOverScreen.cs`

## 練習用シーンで試す（C の Test_C）

メニュー「DeskStage/C/3. 練習用シーンを作る」で、練習用の床の右どなりに、ジャンプ台・敵・ワープの箱（高さ 0.6cm）が並ぶ。名前が「Gimmick_しかけの名前」の箱が、そのしかけになる。左下にハートと敵の数が出る（`App/GimmickDebugHud.cs`、開発用）。

## 確かめていないこと

- 実機での、色の判定（部屋の明るさや、折り紙の光り方で、青・赤・緑と判定されるか）
- 流される速さ、ハートの数、1.5 秒、1 秒の、遊んだときの感じ
