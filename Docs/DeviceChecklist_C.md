# C（キャラ・ゲームプレイ）の実機確認チェック表

対象：A（Mac と iPhone でビルドする人）。週1回の main のビルドのときに、まとめて確かめてください。
C の作る部分は PC で確かめ済みです。ここには、実機でしか確かめられない項目だけを並べています（C_gameplay.md の Step 10〜13）。

## 0. 準備

| やること | 済 |
| --- | --- |
| main を最新にして、Development Build で iPhone に入れる（D のデバッグ表示を出すため） | ☐ |
| Main.unity に Game_System（`Assets/_Project/Gameplay/Prefabs/Game_System.prefab`）が置かれている。なければ、チャットで「Main触ります」と言ってから置く | ☐ |
| 検証用の物のセット（段ボール箱、積み木、本）と、たかさものさしを用意する | ☐ |

- デバッグ表示：3本指で2回たたく。箱をタップすると、その箱の id と高さが出る（Docs/DebugOverlay.md）
- 遊ぶ画面では C のカメラ（PlayCamera）が出ます。AR のカメラ映像が上に重なって見えたら、A の側で AR のカメラを止める必要があります

## 1. スキャンしたステージで遊ぶ（Step 10・13）

B の3つの並べ方（Docs/SampleLayout.md）を1つずつ、並べる → スキャン → 保存 → 遊ぶ。

| 確かめること | 期待 | 結果 |
| --- | --- | --- |
| 全部の箱に乗ってみる | 引っかからない、すり抜けない、跳ねない、はさまらない | |
| 高さ 4.5cm くらいまでの段 | ジャンプで乗れる | |
| それより高い段 | 乗れない（となりに低い物を置けば乗れる） | |
| 指で視点を回してから、スティックを上に倒す | いつも画面の奥へ進む | |
| 高い箱の裏に回る | キャラが見えている（カメラが箱の中に入らない） | |
| 机の端から落ちる | 約1秒落ちて、最後に踏んだチェックポイント（なければスタート）に戻る。タイムは続く | |

- 問題があったら、デバッグ表示で箱をタップして id を見て、下の「問題のメモ」に書く
- 保存した stage.json を PC に取り出して `Assets/StreamingAssets/Stages/<ステージID>/` に置いてもらえると、C が PC の自動テスト（StageTerrainTests）で全部の箱を確かめ直せます。取り出し方は B と相談してください（Xcode の Devices からアプリのデータを取り出す方法など）

## 2. ゲームの進行（Step 11）

D の画面のボタンで、次をすべて起こす。

| 確かめること | 期待 | 結果 |
| --- | --- | --- |
| 保存したステージを選び「あそぶ」 | キャラがスタートに出て奥を向き、タイムが 0 から進む。始めは机全体が見え、1秒でキャラに寄る | |
| 一時停止 | キャラもタイムも止まる | |
| 再開 | また動く | |
| ゴールに触れる | クリアになり、タイムが止まる。初めてか速ければ「新記録」 | |
| クリア画面の「もういちど」 | スタートに戻り、タイムが 0 から | |
| 一時停止メニューの「もういちど」 | スタートに戻り、すぐ遊べる | |
| ステージ一覧へ | キャラが消える | |
| アプリを閉じて開き直し、同じステージを遊ぶ | 最速記録が残っている | |

## 3. コースの配置（Step 12）

たしかめ画面で、子ども（いなければ子ども役）に「スタートとゴールを おいてね」とだけ言って、やってもらう。

| 確かめること | 期待 | 結果 |
| --- | --- | --- |
| 本物の物（箱）の上をタップしてスタートを置く | そこに矢印が出る。向きは置いた子どもから見て奥 | |
| ゴールを置く | そこに旗が出る。もう一度置くと動く | |
| 物の側面をタップする | 置けないと出る | |
| 高すぎる物の上にゴールを置く | 置けるが、「？」の印と案内が出る | |
| チェックポイントを置く・近くをもう一度タップする | 置ける・消える。6個目は置けない | |
| 説明なしで置けたか | 子どもが迷わず置けた | |

## 4. 数値の調整（Step 13）

遊びながら、歩く速さ、重力、ジャンプの高さがちょうどよいかを見る。

| 値 | 今の値 | 感想（速い・遅い・ちょうどよい） | 試した値 |
| --- | --- | --- | --- |
| 歩く速さ | 0.15 m/秒 | | |
| 重力 | 9.8 m/秒² | | |
| ジャンプの高さ | 4cm（乗れる段は 4.5cm まで） | | |

- D のデバッグ表示のスライダーで変える予定ですが、スライダーの仕組み（DebugRegistry）を共通コードに移す相談が終わるまでは、C から値を出せません。それまでは感想だけ書いてください。C が PC で値を変えて、次のビルドで確かめます
- ジャンプの高さを変えると、乗れる段の上限（4.5cm）と、たかさものさしも変わります。変えるときは全員で決めます
