## 机と向き

- 子どもが座る側を手前とし、手前を −Z、奥を +Z とする
- 表の距離は、机の左の辺と手前の辺からの距離（cm）

## 段差（00_overview.md 3.3 の決まり）

| 所 | 高さの差 | 扱い |
| --- | --- | --- |
| 机 → 箱A | 2cm | ジャンプで登れる段 |
| 箱A → 箱B | 1cm | ジャンプで登れる段 |
| 机 → 箱B | 3cm | ジャンプで登れる段 |
| 机・箱A・箱B → 箱C | 11〜14cm | 登れない壁 |

遊び方の流れ：箱A → 箱B（チェックポイント）と登り、降りたら箱C の手前か奥のすき間（12cm 幅）を回り込んでゴールへ行く。

## 手順書と違う所

- 「2cm と 4cm の段」：4cm の段の代わりに、箱B の 3cm と、箱A から箱B への 1cm の段を使っている
- 「壁の前に低い物を置いて登れるようにした所」：入っていない。14cm の壁に登るには 9.5cm 以上の踏み台が要り、手元の物では作れないため。10〜13cm の物が見つかったら、箱C の手前に足す
