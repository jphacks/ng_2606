# 箱の高さの決まり（StepRules）

担当：C。B（箱づくり）と D（緑・赤の印、たかさものさし）も、この決まりを使います。
コードは `Assets/_Project/Gameplay/StepRules.cs`（`StepRules.Classify` が `Walk`、`Jump`、`Wall` を返す）。

## 高さの差の扱い

| 隣の面との高さの差 | 扱い | 子どもへの見せ方 |
| --- | --- | --- |
| 0.8cm未満 | Walk：歩いて登れる | 何も出さない |
| 0.8〜4.5cm | Jump：ジャンプで登れる | 緑の印 |
| 4.5cmを超える | Wall：登れない壁 | 赤の印。となりに低い物を置けば登れる |

- 境目ちょうどの 0.8cm と 4.5cm は Jump です。
- 上りと下りは区別せず、差の大きさだけで決めます。

## 値の理由

| 値 | 理由 |
| --- | --- |
| 0.8cm（歩ける段の上限） | キャラの Step Offset（自動で登れる段差）と同じ値 |
| 4.5cm（跳べる段の上限） | ジャンプの高さ 5cm から、キャラの足が段の角に引っかからないための余裕 0.5cm を引いた値 |

ジャンプの高さを変えたときは、跳べる段の上限も「ジャンプの高さ − 0.5cm」に直し、この表と B・D に知らせます。

## 箱の形の決まり（B の箱づくりと同じ）

| 項目 | 値 | 理由 |
| --- | --- | --- |
| 箱の高さの下限 | 0.5cm | これより低い上面は箱にしない |
| 箱と箱のすき間 | 1.6cm 以上か 0 | 1.6cm はキャラの太さ。それより狭いすき間は、キャラがはさまるのでなくす |
