# 箱の高さの決まり（StepRules）

担当：C。B（箱づくり）と D（緑・赤の印、たかさものさし）も、この決まりを使います。
コードは `Assets/_Project/Gameplay/StepRules.cs`（`StepRules.Classify` が `Walk`、`Jump`、`Wall` を返す）。

> **2026-10-24 の変更（西垣さんの指示）**：実機で、ジャンプ力が足りなかったため、ジャンプの高さを 4cm → **12cm**（3 倍）、重力を 9.8 → **4.9**（半分）、落下の速さの上限を 1 → **0.5 m/秒**（半分）にした。
> 跳べる段の上限は、下の「値の理由」の式（ジャンプの高さ + 約 0.5cm）で **12.5cm** にした。**この 12.5cm は、2026-10-25 の PlayMode の測定で確かめた（1 回のジャンプで、12.5cm の箱まで乗れて、13cm からは乗れない）。** 下の「Step 8 の測定」などの 4cm・4.5cm の記録は、変更前のもの。

> **2026-10-25 の変更（西垣さんの指示）**：**2 段ジャンプ**にした（空中でもう一度ジャンプを押すと、その場から、もう一度 12cm 跳ぶ。`CharacterSettings.maxAirJumps = 1`）。
> 跳べる段の上限を 12.5cm → **22cm** にした。理論上の最大は 12 + 12 + 約 0.5 = 24.5cm（1 回目の頂点ぴったりで 2 回目を押したとき）。頂点の前後 約 0.2 秒の間に押せば、22cm の箱に届く（重力 4.9、頂点まで 約 0.22 秒）ので、24.5cm より少し低くした。**PlayMode の測定（2026-10-25、`SmallWorldPhysicsTests` の「登れる高さの上限を測る」。2 回目は、1 回目の 0.2 秒後に押す）では、2 段ジャンプで 24cm の箱まで乗れて、25cm からは乗れなかった。22cm は、この測定値より 2cm 低いので、押すタイミングが多少ずれても届く。実機では、まだ測っていない。**

## 高さの差の扱い

| 隣の面との高さの差 | 扱い | 子どもへの見せ方 |
| --- | --- | --- |
| 0.8cm未満 | Walk：歩いて登れる | 何も出さない |
| 0.8〜22cm | Jump：ジャンプ（2 段ジャンプまで）で登れる | 緑の印 |
| 22cmを超える | Wall：登れない壁 | 赤の印。となりに低い物を置けば登れる |

- 境目ちょうどの 0.8cm と 22cm は Jump です。
- 上りと下りは区別せず、差の大きさだけで決めます。

## 値の理由

| 値 | 理由 |
| --- | --- |
| 0.8cm（歩ける段の上限） | キャラの Step Offset（自動で登れる段差）と同じ値 |
| 22cm（跳べる段の上限） | 2 段ジャンプの届く高さ（12cm × 2 + 約 0.5cm = 24.5cm）より少し低くした値（頂点ぴったりで押さなくても届く）。1 回ジャンプの場合は、ジャンプの高さ 12cm に、キャラの丸い足元が段のふちを滑り上がる分（約 0.5cm）を足した値。約 0.5cm は、PlayMode の測定で確かめた（12cm のジャンプで 12.5cm まで）。2 段ジャンプは、測定で 24cm まで |

（変更前の経緯）最初の案は「ジャンプ 5cm − 足の余裕 0.5cm」でしたが、Step 8 で測ると、丸い足元が段のふちを滑り上がるため、ジャンプ 5cm では 5.5cm の箱まで登れてしまいました。そこで、決まりの 4.5cm は変えずに、ジャンプの高さを 4cm に下げました。

ジャンプの高さを変えたときは、`登れる高さの上限を測る` テスト（PlayMode）で登れる高さを測り直し、境目が変わるならこの表と B・D に知らせます。

## 箱の形の決まり（B の箱づくりと同じ）

| 項目 | 値 | 理由 |
| --- | --- | --- |
| 箱の高さの下限 | 0.5cm | これより低い上面は箱にしない |
| 箱と箱のすき間 | 1.6cm 以上か 0 | 1.6cm はキャラの太さ。それより狭いすき間は、キャラがはさまるのでなくす |

## 物理の確かめの結果（Step 8、2026-10-24）

練習用シーンと同じ床・箱を PlayMode テスト（`Assets/_Project/Gameplay/Tests/PlayMode/SmallWorldPhysicsTests.cs`）で作り、キャラを動かして確かめました。Test Runner の PlayMode タブの Run All で、いつでも確かめ直せます。

| 床を歩き回る | 揺れや引っかかりがない | 済 |
| 止まって立つ | 浮かず、沈まず、震えない | 済（1秒間の上下の揺れ 0.2mm 未満） |
| 0.5cm の箱 | 歩いて登れる | 済 |
| 2cm、4cm、4.5cm の箱 | ジャンプで登れる | 済 |

| 1cm のすき間 | 落ちずに渡れる | 済 |

### 直したこと

| 起きたこと | 原因 | 直し方 |
| --- | --- | --- |
| 5cm の箱に登れた（5.5cm まで登れた） | キャラの足元が丸く、ジャンプの頂点で箱のふちを滑り上がる | ジャンプの高さを 5cm → 4cm にした。決まりの 0.8cm と 4.5cm は変えていない |
| （念のため） | 段差を自動で登る機能（Step Offset 0.8cm）が空中でも働くと、高い段に乗りやすくなる | Step Offset は地面にいるときだけ使う |

B と D への影響（変更前の記録）：決まりの値（0.8cm、4.5cm）は変わっていないので、箱づくり、緑・赤の印、たかさものさしはそのままで使えます。

**2026-10-24 の変更後：上限が 12.5cm になったので、D の緑・赤の印（`StepMarkLogic.JumpMax`）は 0.125 に直した。たかさものさし（`HeightGauge.md`、`HeightGauge.svg`）は、数字を文書で直したが、図（svg）は直していない。**
