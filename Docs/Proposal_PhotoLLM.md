# 提案（案E）：写真を LLM に渡して、並べた物を認識する

2026-10-24 時点。A 担当（西垣さん）の実機確認で分かったことをもとにした提案です。**まだ決まっていません。**チームで決めるための資料です。

読む人：A・B・C・D の担当。

---

## 1. 提案の要点

今の方式（ARKit の平らな面の検出）だけでは、並べた物の上面が見つからず、高さも安定しません。
そこで、**机の写真を撮り、LLM に渡して、並べた物の種類・数・位置・大きさを答えてもらう**方式を、案 A〜D と並べて検討したい、という提案です。

## 2. 実機で分かったこと（今の方式）

端末：足立さんの iPhone 17。ログは、A が実機で取りました。

| 見たこと | 結果 |
| --- | --- |
| 無地の段ボール箱の上面（高さ約 20cm） | 105 秒映しても、面として見つからなかった。面は机の 1 枚だけ |
| 見つかった面の数（約 1 分間） | 1 枚のまま、増えなかった |
| その 1 枚の大きさ | 約 266×201 cm。実際の机より、はるかに大きい。床や周囲とつながって、広がっているとみられる |
| その面の高さ | 約 0.6〜1.7 cm の間で揺れた。手順書の目標（±3mm 未満）の数倍 |
| 箱の上をタップして得た高さ | 20.3 cm（特徴点）。面ではなく、点として高さは取れる |
| メッシュ（LiDAR）の機能 | 初期化に失敗した。この端末では使えないとみられる |

**分かっていないこと**
- 模様のある物（絵本、積み木）で、上面が見つかるか。最後の実行で、何を置いたかは、記録していない。
- 案 B〜D（並べ方の決まり、模様シート、模様の箱）で、改善するか。P0 の検証（A の Step 4）は、省略している。

## 3. 案E の流れ

1. 子どもが机に物を並べる。
2. アプリで、机の写真を撮る。必要なら、大きさの基準になる物（定規、決まったカード）を、一緒に写す。
3. 写真を LLM に渡し、物ごとに、種類、上面の位置、大きさ、高さを答えてもらう。
4. 答えを、B の箱（BoxData）に変える。
5. たしかめ画面で、子どもが、タップで直す（B の Step 9 の補助）。

## 4. 良い点と難しい点

| | 内容 |
| --- | --- |
| 良い点 | 無地・黒・つやのある物でも、見分けられる可能性がある。ARKit の面の検出に、頼らない |
| 良い点 | 「何の物か」が分かるので、後で、遊びに使える |
| 難しい点 | 高さを、±1cm で、安定して答えさせられるか。写真 1 枚では、大きさと距離の区別がつかない。基準の物が要るかもしれない |
| 難しい点 | 同じ写真でも、答えが毎回変わりうる。再現しにくい |
| 難しい点 | 写真を外部に送ることになる。子どもの写真の扱いを、決める必要がある |
| 難しい点 | 通信の待ち時間、費用、通信できないときの扱い |

**A 担当の報告**：Claude で試したところ、正確に測れた、とのこと。条件（基準の物の有無、角度）と、実測との差の数字は、**まだ記録していない**。

## 5. 決めること

| 項目 | 内容 |
| --- | --- |
| 精度の基準 | 箱の高さは、実物と ±1cm 以内（C の「箱の高さの決まり」、A_ar.md の Step 13 と同じ）を、そのまま使うか |
| 写真の送り先 | どのサービスに送るか。送ってよい写真の条件 |
| 個人情報 | 顔や、個人の分かる物が写ったときの扱い。写真を、保存するか、消すか |
| 通信できないとき | 今の方式（ARKit）に戻すか、手で並べて入力させるか |
| ARKit との使い分け | 案E だけにするか、ARKit のタップで取れる高さと組み合わせるか |

## 6. 各担当への影響

| 担当 | 影響 |
| --- | --- |
| A（スキャン） | 面の安定化（Step 11）の位置づけが変わる。撮影と、LLM への依頼を、A が持つのか、別の担当が持つのか、決める必要がある。机の決定（Step 8）は、そのまま使える |
| B（箱・データ） | 入力が、ScanContext.Surfaces から、LLM の答えに変わる可能性。箱の形（BoxData）は、変えない |
| C（ゲーム） | 変わらない。箱の高さの決まりは、そのまま |
| D（UI） | 撮影の画面と、待ち時間の表示が、増える |

## 7. 採用を決める前に、取りたい数字

必須ではありません。**やる場合の最小限**です。

- 物を 3 通り（本、積み木、段ボール箱など）用意し、各 3 枚ずつ、角度を変えて撮る。
- 定規で測った、高さと上面の大きさを記録する。
- LLM の答えとの差を、表にする。±1cm に入った割合が、判断の材料になる。

結果は、`Docs/PlaneCheck.md` と同じ形の表にまとめるとよい。
